## Skills para Codex e Claude

Desenvolvi cinco skills para planejar animações, produzir sprites e implementar interfaces a partir de referências visuais. Cada projeto tem um guia de uso em inglês.

| Skill | O que faz |
| --- | --- |
| [Anime Animator](https://github.com/gustavinzika/anime-animator) | Anima ilustrações com máscaras e efeitos em camadas e verifica os pixels fora da área editada. |
| [Motion Planner](https://github.com/gustavinzika/motion-planner) | Mapeia regiões de movimento e pontos de fixação em uma imagem. Entrega um manifesto JSON e um mapa visual. |
| [Sprite Planner](https://github.com/gustavinzika/sprite-planner) | Define peças, pivôs e ordem de desenho para sprites articulados do Hyakki Yakō. |
| [Pixel Art Maker](https://github.com/gustavinzika/pixel-art-maker) | Monta e valida sprites, atlas e animações para o Hyakki Yakō. |
| [Image to Web](https://github.com/gustavinzika/image-to-web) | Orienta a implementação de interfaces responsivas a partir de imagens e a verificação no navegador. |
